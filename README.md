# Кости и Клинки

![Tests](https://github.com/shpachenkoartem-droid/RPG-Java-Game/actions/workflows/tests.yml/badge.svg)

Консольная RPG на Java: герой путешествует по локациям, сражается с монстрами,
покупает снаряжение и зелья. Урон считается бросками костей в стиле D&D (например, 1d6 + 1).
Прохождение занимает около 10 минут.

Учебный проект для изучения ООП и проектирования архитектуры.

Развиваю и поддерживаю с июня 2026.


## Возможности
- Локации: магазин, лес.
- Пошаговые бои с врагами; с врагов выпадает лут.
- Магазин оружия, брони и зелий.


## Архитектура
Проект выполняется с помощью архитектуры MVC: model, view, controller.
    Model отвечает за основные действующие классы.
    View отвечает за вывод.
    Controller соединяет их вместе.

Иерархия классов построена на наследовании и абстракции:

Fighter -> PlayableHeroes / Enemy это конкретные персонажи;

Item -> Equipment / Potion это конкретные предметы.

Новый враг или предмет добавляется отдельным классом-наследником без изменения логики боя.


## Тестирование
В рамках проекта было разработано 22 unit-теста на JUnit 5. Они выявили ошибки в логике покупки и экипировки:
- Оружие, полученное вне магазина, нельзя было надеть.
- Количество кубиков умножало выпавший результат, а не кидало новый.
- Количество монет могло уйти в минус.
    

## Запуск
Требуется Java 21+.

#Игра
mvn compile exec:java

#Тесты
./mvnw

Команда в windows: mvnw.cmd

Также игру можно запустить из IDE через класс com.game.Main.
